# Eby: AI-Powered Virtual Assistant App

Eby is a feature-rich virtual assistant app that uses AI, speech recognition, and text-to-speech technologies to provide an engaging and interactive experience. The app is built with Flutter, Firebase, and Rive animations.

---

## Features

- **Voice Commands**: Interactive voice communication with AI responses.
- **Custom Animations**: Rive-powered animations for dynamic visual effects.
- **Speed Dial Settings**: Expanding floating action buttons for easy navigation.
- **Speech-to-Text (STT)**: Recognizes spoken input and converts it into text.
- **Text-to-Speech (TTS)**: Converts AI-generated responses into spoken output.
- **Firebase Integration**: User authentication and real-time interactions.
- **Custom Buttons**: Bounce animations for enhanced user feedback.
